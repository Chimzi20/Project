# UK Police Crime Data Analysis Using PySpark

## Project Overview

This project focuses on analysing UK police crime data using Python and Apache Spark (PySpark). The analysis explores recorded crime patterns in Leicestershire, with a focus on monthly crime counts for 2022 and 2023.

The project demonstrates how big data processing tools can be used to process structured datasets, perform data transformations, aggregate crime records, and examine crime trends over time.

## Project Objectives

- Analyse UK police crime data using PySpark.
- Examine monthly crime counts for 2022 and 2023.
- Apply Spark DataFrame operations to filter, transform, and aggregate data.
- Use Spark SQL to query and analyse structured crime records.
- Develop practical skills in data processing and exploratory data analysis.

## Tools and Technologies

- **Python:** Data processing and analysis.
- **Apache Spark (PySpark):** Distributed data processing.
- **Spark SQL:** Querying and aggregating structured datasets.
- **Jupyter Notebook:** Interactive coding and analysis.
- **Kaggle:** Notebook development environment.

## Project Methodology

The project uses PySpark to process police crime records and organise the data for analysis. DataFrame operations and SQL-based techniques are applied to retrieve relevant records, group crime incidents by month, and calculate monthly crime counts.

The analysis focuses on Leicestershire and compares monthly crime activity across 2022 and 2023 to support the exploration of temporal patterns in recorded crime.
