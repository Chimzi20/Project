# Data Analytics and Machine Learning Portfolio

## Overview

Welcome to my Data Analytics and Machine Learning Portfolio. This repository showcases three projects demonstrating my skills in data analysis, big data processing, predictive modelling, and data-driven problem-solving.

The projects cover UK police crime analysis across four areas, Titanic passenger survival prediction, and predicting electric vehicle (EV) penetration in West Africa. Each project applies analytical and computational techniques to explore real-world problems and generate insights from data.

## Project 1: UK Police Crime Data Analysis Using PySpark

### Overview

This project analyses UK police crime data across four areas: **Leicestershire, Lincolnshire, Nottinghamshire, and the City of London**. Using Python and Apache Spark (PySpark), the project explores crime records and examines patterns in recorded crime, including monthly crime counts for 2022 and 2023.

The aim is to demonstrate how large datasets can be processed, transformed, and analysed to identify crime patterns over time and across different geographical areas.

### Key Activities

- Process and analyse police crime records from four UK areas.
- Use PySpark DataFrames to filter, transform, and aggregate data.
- Apply Spark SQL to query structured crime datasets.
- Examine monthly crime counts and compare crime patterns across 2022 and 2023.
- Explore geographical and temporal patterns in recorded crime.

### Technologies

Python, Apache Spark, PySpark, Spark SQL, Pandas, Jupyter Notebook.

## Project 2: Titanic Passenger Survival Prediction

### Overview

This project explores passenger survival on the Titanic using data analysis and machine learning techniques. The objective is to examine survival rates and investigate how passenger characteristics may have influenced survival outcomes.

Predictive modelling is used to identify patterns in the historical data and estimate whether a passenger survived.

### Key Activities

- Explore and prepare the Titanic passenger dataset.
- Analyse survival rates and passenger characteristics.
- Investigate relationships between passenger attributes and survival outcomes.
- Develop a machine learning model to predict passenger survival.
- Assess model performance using appropriate classification evaluation techniques.

### Technologies

Python, Pandas, NumPy, data visualisation, and machine learning libraries, as applicable to the implementation.

## Project 3: Predicting Electric Vehicle Penetration in West Africa

### Overview

This project investigates the potential adoption of electric vehicles across West Africa using a data-driven predictive modelling approach. The study explores factors that may influence EV penetration and examines how economic, demographic, infrastructural, environmental, and policy conditions relate to electric mobility adoption.

The research uses secondary data from countries with established EV markets and West African countries to investigate adoption patterns and develop a classification model for predicting EV penetration levels in the region.

### Key Activities

- Collect and prepare secondary data relevant to EV adoption.
- Investigate economic indicators, population, urbanisation, electricity access, renewable energy, charging infrastructure, fuel prices, government policies, and public awareness.
- Explore factors associated with electric vehicle adoption.
- Apply and compare machine learning classification algorithms.
- Classify EV penetration into low, medium, and high adoption categories.
- Evaluate model performance using accuracy, precision, recall, and F1-score.
- Explore the implications of the findings for sustainable transportation and electric mobility development in West Africa.

### Technologies

Python, Pandas, PySpark, machine learning, data preprocessing, classification algorithms, and model evaluation techniques.
